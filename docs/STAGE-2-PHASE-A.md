# H.A.I.V.A. Stage 2 — Phase A

## Prompt & Agent Builder

Stage 2 Phase A adds a structured builder for prompt and agent specifications.

The capability supports:

- agent role selection
- goal definition
- optional context
- explicit constraints
- tool requirements
- output format selection
- validation of required inputs

Verification is chained through the existing Phase 1–10 tests before the Stage 2 Phase A tests run.
